## 2. 产品目标

实现一个“可直接面向客户”的响应式投资组合仪表盘，使用户能够创建和切换组合、录入交易、查看持仓、触发行情同步，并通过交互图表理解市值、盈亏、配置和历史表现。

## 3. 页面范围

### 3.1 应用壳层

- 桌面侧边导航与移动端可展开导航。
- 页面：Dashboard、Portfolios、Holdings、Transactions、Data Status。
- 当前组合选择器和同步状态始终可见。
- 统一颜色、字体、间距、金额格式和图表色板。

### 3.2 组合管理

- 组合列表、创建、重命名和归档。
- 无组合时显示首次创建引导。
- 当前组合 ID 写入 URL，刷新后保持选择。

### 3.3 交易与持仓

- 股票/ETF 搜索。
- 买入和卖出表单。
- 当前持仓表与交易历史。
- 超量卖出、重复提交和字段错误提示。

### 3.4 行情状态

- Data Status 页面和手动同步按钮。
- 显示 provider、运行状态、成功/失败数量和最后同步时间。
- 展示 `FRESH`、`STALE`、`UNAVAILABLE`。

### 3.5 估值与分析

- 总市值、总成本、未实现盈亏、收益率摘要卡。
- 资产配置环形图。
- 估值历史折线图。
- 无价格持仓单独提示，不伪造为零价格。

- 金额、价格、数量和比例按十进制字符串接收。

## 5. 状态与交互

### 5.1 加载

- 首屏立即显示固定高度骨架。
- 图表和表格加载期间不造成大幅布局跳动。
- 后台刷新保留最后成功数据。

### 5.2 空状态

- 无组合：引导创建第一个组合。
- 无持仓：引导搜索股票或 ETF 并录入买入。
- 无历史快照：解释需要完成行情同步。

### 5.3 错误

- 显示用户可理解消息、重试按钮和 `requestId`。
- 字段错误显示在对应表单控件附近。
- 不展示 Java 堆栈、SQL、密钥或完整供应商响应。

### 5.4 行情状态

- `FRESH`：正常显示价格交易日和来源。
- `STALE`：显示非阻断提示并继续使用最后价格。
- `UNAVAILABLE`：显示“暂无价格”，且解释未计入市值和配置。
